Cria uma intervenção (usa \textquotesingle{}\doxylink{struct_ocorrencias}{Ocorrencias}\textquotesingle{}, \textquotesingle{}\doxylink{struct_bombeiros}{Bombeiros}\textquotesingle{} e \textquotesingle{}\doxylink{struct_equipamentos}{Equipamentos}\textquotesingle{} para associar recursos existentes).

\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*} Lógica Complexa de Validação e Alocação\+:
\begin{DoxyEnumerate}
\item Pré-\/condição\+: Verifica se existem ocorrências registadas.
\item Gera ID automático e redimensiona a memória (realloc) se necessário.
\item Associa a uma Ocorrência existente (validação de chave estrangeira).
\item {\bfseries{Alocação de \doxylink{struct_bombeiros}{Bombeiros}}}\+:
\end{DoxyEnumerate}
\begin{DoxyItemize}
\item Conta quantos bombeiros têm estado \textquotesingle{}DISPONIVEL\textquotesingle{}.
\item Solicita ao utilizador quantos quer alocar (limitado aos disponíveis).
\item Para cada bombeiro escolhido\+: valida se existe, se não é duplicado na lista e se está realmente disponível.
\item IMPORTANTE\+: Altera o estado do bombeiro para \textquotesingle{}EM\+\_\+\+INTERVENCAO\textquotesingle{}.
\end{DoxyItemize}
\begin{DoxyEnumerate}
\item {\bfseries{Alocação de \doxylink{struct_equipamentos}{Equipamentos}}}\+:
\end{DoxyEnumerate}
\begin{DoxyItemize}
\item Segue a mesma lógica dos bombeiros. Altera o estado para \textquotesingle{}EM\+\_\+\+USO\textquotesingle{}.
\end{DoxyItemize}

\item Regista as datas e horas de início.
