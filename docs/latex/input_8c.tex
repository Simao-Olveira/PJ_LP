Limpa o buffer de entrada (stdin). Consome todos os caracteres pendentes no buffer de entrada num ciclo até encontrar uma quebra de linha (\textquotesingle{}\textbackslash{}n\textquotesingle{}) ou o fim do ficheiro (EOF).
