Menu principal que orquestra a navegação entre todos os módulos.

Menu principal que orquestra a navegação entre todos os módulos.

** Lógica de Navegação: Apresenta as opções principais e delega o controlo para os submenus específicos. Ao selecionar a opção '0' (Sair), invoca as funções de limpeza de memória (libertarMem...) para garantir que todos os recursos alocados dinamicamente são devolvidos ao sistema operativo antes do encerramento.
