◆ adicionarQuartel()

void adicionarQuartel ( Quarteis * quarteis)

Adiciona um novo quartel ao sistema.

** Lógica de Criação:

  1. Gera um ID sequencial.
  2. Redimensiona o array principal se estiver cheio.
  3. Aloca memória dinâmica para duas strings diferentes: 'nome' e 'local'. O tamanho alocado é estritamente o necessário (strlen + 1) para otimizar memória.

◆ atualizarDadosQuartel()

void atualizarDadosQuartel ( Quartel * quartel)

Submenu para atualizar dados de um quartel.

Atualiza dados de um quartel (função auxiliar).

** Permite a edição individual de campos. O uso de realloc nas strings (nome e local) garante que a memória se ajusta ao tamanho dos novos dados.

◆ carregarQuarteis()

void carregarQuarteis ( Quarteis * quarteis)

Carrega dados dos quartéis do ficheiro binário.

Carrega os dados do ficheiro binário.

** Lê os contadores iniciais. Para cada quartel, lê os dados primitivos e, sequencialmente, o tamanho e o conteúdo das strings 'nome' e 'local', alocando memória dinâmica para cada uma.
