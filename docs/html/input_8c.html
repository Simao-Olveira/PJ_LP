◆ cleanInputBuffer()

void cleanInputBuffer ( )

Limpa o buffer de entrada (stdin). Consome todos os caracteres pendentes no buffer de entrada num ciclo até encontrar uma quebra de linha ('\n') ou o fim do ficheiro (EOF). Isto impede que caracteres "lixo" deixados por leituras anteriores (como um Enter pendente) afetem a próxima solicitação de dados.

Limpa o buffer de entrada (stdin) para evitar erros de leitura.

Lê uma string do teclado de forma segura (remove o \n final).

*- Se for um \\n (Enter), substitui-o por \\0 (fim de string) para o texto ficar limpo.

  • Se NÃO for um \\n, significa que o utilizador escreveu mais texto do que cabia. Nesse caso, chama a função cleanInputBuffer para descartar o excesso e impedir erros futuros.
